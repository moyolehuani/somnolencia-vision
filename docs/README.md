# Documentación

Antes que nada:

- [estado_actual.md](estado_actual.md) dice qué está escrito y cómo se probó.
- [tareas_pendientes.md](tareas_pendientes.md) dice lo que falta, tarea por tarea.
- [../AGENTS.md](../AGENTS.md) resume las reglas del proyecto. Es lo que debe leer un asistente de IA antes de ayudar.

Orden de lectura sugerido para alguien que llega por primera vez:

1. [arquitectura.md](arquitectura.md). Qué piezas tiene el sistema y cómo se hablan entre sí.
2. [decisiones.md](decisiones.md). Qué ya está decidido y qué falta, con la razón de cada cosa.
3. [plan_de_trabajo.md](plan_de_trabajo.md). Los pasos en orden, con fechas y responsables.
4. [flujo_git.md](flujo_git.md). Cómo subir trabajo sin romper el de los demás.
5. [algoritmos_y_modelos.md](algoritmos_y_modelos.md). Qué algoritmos son propios y dónde entra la IA.
6. [datos_y_gobernanza.md](datos_y_gobernanza.md). Qué datos hay, de quién son y cómo se cuidan.
7. [evaluacion.md](evaluacion.md). Cómo se demuestra que el sistema funciona.
8. [despliegue_y_demo.md](despliegue_y_demo.md). Cómo se instala, se congela y se presenta.
9. [guia_de_supervision.md](guia_de_supervision.md). Para quien coordina al equipo.

Cuando una decisión cambie, se actualiza primero `decisiones.md` y después el documento afectado. Así siempre hay un solo lugar donde ver qué está vigente.
